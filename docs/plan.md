# pointer 기획

폰을 발표 리모컨 겸 레이저 포인터로 쓰는 앱. 맥·윈도우에서 발표하고, 아이폰 앱이나
안드로이드 브라우저로 조종한다. 스토어 공개가 목표.

상태 (2026-10-12): 1단계 구현 완료, 검증 중. 결정 사항은 맨 아래 "정한 것".

## 구성

```
데스크톱 앱 (Electron, 맥·윈도우)
  - 발표 화면 (청중용 전체화면 + 발표자 화면)
  - 리모컨 서버 (같은 와이파이, WebSocket)
  - 안드로이드용 웹 리모컨도 여기서 내려준다
        |
        +-- iOS 앱 (Expo)           볼륨 버튼, 진동, 에어 포인터, QR 스캔
        +-- 안드로이드 (Chrome)      설치 없이 QR 로 접속
```

같은 와이파이 직접 연결이 기본. 반응이 가장 빠르고, 서버 비용이 없고, 자료가 밖으로
안 나간다. 와이파이가 기기 간 통신을 막는 곳을 위한 인터넷 중계는 2단계.

저장소는 pnpm 모노레포로 나눈다.

- `apps/desktop` Electron
- `apps/mobile` Expo (iOS, 나중에 안드로이드 네이티브도 여기서)
- `packages/remote-web` 안드로이드용 웹 리모컨 (데스크톱 앱이 서빙)
- `packages/protocol` 폰과 데스크톱이 주고받는 메시지 타입 (세 곳이 같이 씀)

## 조사에서 나온 제약

### iOS 볼륨 버튼은 심사 거절 위험이 있다
App Store 심사 가이드라인 2.5.9 가 볼륨 버튼 같은 기본 스위치의 동작을 바꾸는 앱을
거절 대상으로 둔다. 2010년 Camera+ 의 볼륨 셔터, 2017년 Astro HQ 업데이트가 이 조항으로
거절됐다. 볼륨을 원래 값으로 되돌리는 방식은 "하드웨어 동작 방해" 로 따로 걸릴 수 있다는
경고도 있다. 숨겨진 스위치로 몰래 켜는 방식은 하면 안 된다.

대응:
- 볼륨 버튼은 설정에서 사용자가 직접 켜는 기능으로 두고, 심사 노트에 동작을 그대로 설명한다.
- 거절되면 원격 설정으로 끌 수 있게 만들어 둔다 (스토어 빌드에서만 끄고 TestFlight 는 유지).
- 심사에 안전한 대체 수단을 같이 넣는다: 액션 버튼 (iPhone 15 Pro 이상, App Intent),
  제어 센터 버튼 (iOS 18), 블루투스 클리커·키보드, 잠금화면 버튼 (Live Activity, 2단계).

### 맥 App Store 에서는 "다른 앱 조종" 이 안 된다
맥 App Store 앱은 샌드박스 안에서 돌아야 하는데, 다른 앱에 키 입력을 보내는
(CGEventPost, 손쉬운 사용 권한) 방식이 샌드박스와 맞지 않는다. 같은 패턴의 앱이 2.4.5 로
거절된 사례가 있다.

대응: 맥은 App Store 대신 홈페이지에서 직접 배포한다 (Developer ID 서명 + 공증, 기존 Apple
개발자 계정으로 가능). 경고 없이 열리고 모든 기능을 넣을 수 있다.

### 윈도우는 Microsoft Store 가 가장 쉽다
2025-09 부터 개인 개발자 등록이 무료이고, 스토어가 앱에 서명을 해 준다. 따로 코드서명
인증서를 사지 않아도 "알 수 없는 게시자" 경고가 안 뜬다. Electron 은 electron-builder 로
MSIX 패키지를 만들어 올린다.

## 비슷한 앱과 차별점

- Power Remote Pro (iOS, 유료): PPT·Keynote·구글 슬라이드·PDF, 맥·윈도우
- Wireless Presenter (iOS, 무료+인앱): QR 연결, 가상 레이저, 자이로 에어 마우스
- WPS Office: 터치 레이저, 발표 메모, QR 연결
- RemoteSlide (크롬 확장): 구글 슬라이드 전용, 화면 미리보기, 가상 레이저
- 하드웨어: 로지텍 R500 (실제 레이저), Spotlight (스포트라이트·돋보기, 고가)

넘기기·레이저·QR 연결은 이미 흔하다. 잡을 차별점:

1. 로지텍 Spotlight 급 화면 효과 (스포트라이트, 돋보기, 판서) 를 소프트웨어로, 무료 폰으로
2. 맥·윈도우·iOS·안드로이드 전부, 계정 없이, 자료가 밖으로 안 나감
3. 발표자 중심 기능: 진동 타이머, 리허설 리포트, 장별 메모, 발표자 화면
4. 하드웨어 버튼으로 넘기기 (볼륨, 액션 버튼, 클리커)

## 기능

### 1단계: 데스크톱 앱 + 안드로이드 웹 리모컨

데스크톱 (맥·윈도우)
- 자료 열기: PDF 전부 (16:9, 4:3, A4 세로, 장마다 크기 다른 것, 수백 장, 암호),
  이미지 여러 장·폴더. 드래그 앤 드롭, 최근 파일
- 렌더링은 pdf.js (설치할 외부 도구 없음)
- 모니터가 2개면 청중 화면은 프로젝터에 전체화면, 노트북엔 발표자 화면
  (현재·다음·메모·타이머) 자동 배치. 1개면 지금처럼 전체화면만
- 장별 발표 메모 작성 (파일별로 로컬 저장)
- 리모컨 연결: QR 페어링, 연결된 기기 목록·끊기, 자동 재연결
- 화면 효과: 레이저, 스포트라이트 (포인터 주변만 밝게), 돋보기, 판서 (장 넘기면 지워짐)
- 화면 가리기 (검정·흰색)
- 키보드, 블루투스 클리커 (PageUp/PageDown 을 보내는 일반 클리커 전부)
- 발표 중 화면 꺼짐 방지

안드로이드 웹 리모컨 (Chrome)
- 넘기기 버튼 + 진동, 장 목록에서 이동
- 레이저·스포트라이트·돋보기·판서 (슬라이드를 터치)
- 현재·다음 장, 발표 메모
- 타이머: 목표 시간 카운트다운, 5분·1분 남았을 때 진동
- 안 되는 것: 볼륨 버튼, 에어 포인터 (브라우저가 막음)

### 2단계: iOS 앱

- 1단계 리모컨 기능 전부
- 볼륨 버튼 넘기기 (설정에서 켜기, 위 심사 대응 참고)
- 액션 버튼·제어 센터로 넘기기
- 에어 포인터: 버튼을 누른 채 폰을 휘두르면 레이저가 따라감 (자이로)
- 넘길 때·시간 알림 햅틱
- QR 스캔으로 연결, 같은 와이파이의 맥·윈도우 자동 찾기 (Bonjour), 마지막 기기 자동 재연결
- 화면 꺼짐 방지

### 3단계: 아무 발표 앱이나 조종 (직접 배포판)

- PPT, Keynote, 구글 슬라이드, Figma, Canva 등을 원래 앱에서 띄워 두고 키 입력으로 넘김
- 레이저·스포트라이트·판서는 화면 맨 위 투명 창에 그림
- 폰에 실제 화면 미리보기 (화면 녹화 권한)
- 권한: 맥은 손쉬운 사용 + 화면 기록, 윈도우는 추가 권한 없음

### 4단계: 나머지

- 리허설 모드: 장별 사용 시간 리포트
- 잠금화면·다이내믹 아일랜드 버튼 (Live Activity), Apple Watch
- 인터넷 중계 (와이파이가 기기 간 통신을 막는 곳)
- 안드로이드 네이티브 앱 (볼륨 버튼)
- 자동 업데이트, 홈페이지 (다운로드 + 개인정보처리방침)

## 배포

| 플랫폼 | 경로 | 비고 |
| --- | --- | --- |
| iOS | App Store | 볼륨 버튼 심사 리스크 |
| 맥 | 홈페이지 직접 배포 | Developer ID 서명 + 공증 |
| 윈도우 | Microsoft Store (+ 홈페이지) | 개인 등록 무료, 스토어가 서명 |
| 안드로이드 | 웹 (설치 없음) | 네이티브는 4단계 |

개인정보: 계정 없음, 자료는 기기 안에서만. 분석 도구를 안 넣으면 스토어 개인정보 라벨을
"수집 안 함" 으로 낼 수 있다. iOS 는 로컬 네트워크·카메라·모션 권한 사용 이유 문구가 필요하다.
